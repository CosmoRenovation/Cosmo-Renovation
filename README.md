société immobilière, Créaxia, Crenovia, école).

## Installer l'équipe

- **Claude Code** (sur ce dépôt, rien à faire : `.claude/` pointe vers le plugin). Ailleurs :
  `/plugin install equipe-cosmo --marketplace CosmoRenovation/Cosmo-Renovation`
- **Cowork** : Personnaliser → Plugins → « + » (plugins personnels) → *Ajouter une place de marché* →
  `CosmoRenovation/Cosmo-Renovation` → installer **Équipe Cosmo**. Pour une mise à jour : bouton *Mettre à jour*.
