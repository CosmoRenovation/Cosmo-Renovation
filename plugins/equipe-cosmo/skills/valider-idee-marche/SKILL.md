# Valider une idée sur le marché

Inspiré de `project-idea-validator` / `market-researcher` (VoltAgent, MIT) et `competitive-brief` (Anthropic, Apache-2.0). Réécrit.

1. **Hypothèse** : « [cible] a [problème] et paierait [prix] pour [solution] ».
2. **Recherche** (WebSearch) : concurrents directs dans la zone, leurs offres et prix publics, avis clients (ce qu'on
   leur reproche), tendances (recherches, réglementation, aides publiques type MaPrimeRénov' le cas échéant).
3. **Taille utile** : nombre approximatif de clients atteignables localement, panier moyen → CA potentiel (fourchette).
4. **Différenciation** : ce que Corentin peut faire mieux / autrement, et comment le prouver.
5. **Test pas cher** proposé : 1 action à < 200 € ou < 1 jour pour valider (page, post, appels à 10 prospects…).
6. **Verdict** : GO test / À creuser / STOP, avec les sources (URL) de chaque affirmation chiffrée.
