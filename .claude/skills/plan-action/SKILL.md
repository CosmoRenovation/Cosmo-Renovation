# Plan d'action

Inspiré de `writing-plans` / `executing-plans` (obra/superpowers, MIT). Réécrit pour tous types de projets.

## Écrire le plan
- Chaque étape : **un résultat vérifiable** (« statuts relus par l'avocat », pas « travailler les statuts »),
  un responsable (agent ou Corentin), une durée estimée, ses dépendances, comment on vérifie qu'elle est faite.
- Marquer 🔐 les étapes qui nécessitent une validation de Corentin (argent, signature, envoi externe).
- Mettre les étapes indépendantes en parallèle.
- Enregistrer dans `bureau/rapports/AAAA-MM-JJ-plan-<projet>.md` et reporter les tâches dans `bureau/taches.md`.

## Exécuter
- Étape par étape ; après chaque lot, cocher dans le plan avec la preuve (lien, fichier, référence).
- Une étape 🔐 → `file-validation`, et on n'avance pas sur ce qui en dépend.
- Si le plan s'avère faux (nouvelle info, blocage), s'arrêter et proposer un plan corrigé plutôt qu'improviser.
