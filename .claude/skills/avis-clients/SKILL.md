# Avis clients

Inspiré de `review-reputation` (anthropics/knowledge-work-plugins, Apache-2.0). Réécrit.

- Avis positif : remercier, personnaliser (nature du chantier), sans données personnelles.
- Avis négatif : ne jamais répondre à chaud ; faits vérifiés auprès de Corentin ; réponse factuelle, empathique,
  proposition de contact privé ; si diffamatoire → `juriste`.
- Fin de chantier : message de demande d'avis avec lien, envoyé après validation.
- Point mensuel : note moyenne, nombre d'avis, thèmes récurrents → amélioration.
