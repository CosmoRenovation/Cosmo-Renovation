# Conseil technique

Inspiré de `cto-advisor` (alirezarezvani/claude-skills, MIT) et `system-design` (Anthropic, Apache-2.0). Réécrit.

1. **Le besoin métier d'abord** : quel problème, pour quelle entité, combien de personnes, quel budget mensuel.
2. **Existant** : outils déjà utilisés (Gmail, Google Drive, Notion, Asana, Canva…) — préférer ce qui existe.
3. **2-3 solutions** : solution clé en main (SaaS), solution « connectée » (outils existants + automatisation),
   solution sur mesure — pour chacune : coût mensuel/annuel, temps de mise en place, difficulté pour Corentin,
   dépendance/réversibilité, conformité RGPD (hébergement des données), conformité facturation électronique
   (obligations à venir pour les entreprises françaises — vérifier le calendrier en vigueur).
4. **Recommandation** expliquée sans jargon (définir chaque terme technique en une phrase).
5. **Plan de mise en place** via `plan-action` ; toute souscription payante = validation.

Pour le code : produire du code simple, testé, documenté, et ne jamais demander à Corentin de lancer une commande
qu'il ne comprend pas sans expliquer ce qu'elle fait.
